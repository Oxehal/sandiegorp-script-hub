# ⚡ San Diego RP — Automation Script & Web Hub

A high-performance, responsive landing page and product showcase for the **San Diego RP (Roblox)** automation script. Designed in a modern dark-orange aesthetic with real-time UI previews, tier breakdowns, and injector compatibility matrix.

---

## 🚀 Key Script Features

- **Extreme Velocity (350 studs/s):** High-speed travel across highway sectors without artificial slowdowns.
- **Checkpoint Bypass (GhostBarriers):** Seamlessly passes checkpoints (KPP), fences, and barriers by dynamically toggling collision geometry.
- **Auto Interaction & Alignment:** Automatic ProximityPrompt (E-key) detection, angle alignment, and auto-purchase routines.
- **Multiple Farm Modes:** Support for Mona Lisa, El Capo, and Cargo Truck rotations.
- **Customizable Themes:** Switch dynamically between *Dark Graphite* and *Indigo Neon* UI layouts.

---

## 🌐 Web Hub Features

- **Dynamic Theme Switcher:** Interactive live preview of script GUI themes (*Dark Graphite* / *Indigo Neon*).
- **Interactive Pricing Matrix:** Clear tiers (1-Day Trial, 1-Week, 1-Month, and Lifetime keys).
- **Compatibility Matrix:** Up-to-date compatibility and sUNC ratings across popular injectors (Real, Xeno, Solara, Delta, Volt, Wave).
- **Direct Checkout Flow:** Instant access to Telegram and Discord contacts with one-click clipboard copying.
- **Zero External Dependencies:** Built with pure HTML5, CSS3 (Flexbox/Grid/Animations), and vanilla JavaScript.

---

## 🛠️ Tech Stack

- **Markup:** HTML5 (semantic structure)
- **Styling:** Vanilla CSS3 (custom properties, modern glassmorphism, responsive design)
- **Scripting:** Vanilla JavaScript (ES6+, Intersection Observer API, Clipboard API)
- **Automation / Logic:** Luau / Roblox Studio API (Raycasting, BodyMovers/LinearVelocity)

# ⚡ San Diego RP — Скрипт автоматизации и веб-платформа

Высокопроизводительный адаптивный лендинг и витрина продукта для скрипта автоматизации **San Diego RP (Roblox)**. Дизайн выполнен в современной темно-оранжевой стилистике и включает предварительный просмотр интерфейса в реальном времени, описание тарифных планов и матрицу совместимости с инжекторами.

---

## 🚀 Ключевые возможности скрипта

- **Экстремальная скорость (350 стадов/с):** Быстрое перемещение по участкам шоссе без искусственных замедлений.
- **Обход контрольных точек (GhostBarriers):** Беспрепятственное прохождение через КПП, заборы и шлагбаумы благодаря динамическому отключению коллизии.
- **Автоматическое взаимодействие и выравнивание:** Автоматическое обнаружение объектов (ProximityPrompt / клавиша E), выравнивание угла обзора и функции автоматической покупки.
- **Различные режимы фарма:** Поддержка маршрутов «Мона Лиза» (Mona Lisa), «Эль Капо» (El Capo) и перевозки грузов (Cargo Truck).
- **Настраиваемые темы:** Динамическое переключение между темами интерфейса *Dark Graphite* и *Indigo Neon*.

---

## 🌐 Возможности веб-платформы

- **Динамический переключатель тем:** Интерактивный предпросмотр тем графического интерфейса скрипта (*Dark Graphite* / *Indigo Neon*) в реальном времени.
- **Интерактивная таблица тарифов:** Четкое разделение по уровням доступа (пробный период 1 день, ключи на 1 неделю, 1 месяц и пожизненный доступ).
- **Матрица совместимости:** Актуальная информация о совместимости и рейтингах sUNC для популярных инжекторов (Real, Xeno, Solara, Delta, Volt, Wave).
- **Прямая связь для покупки:** Мгновенный доступ к контактам в Telegram и Discord с возможностью копирования в буфер обмена в один клик.
- **Отсутствие внешних зависимостей:** Сайт создан с использованием чистого HTML5, CSS3 (Flexbox/Grid/анимации) и ванильного JavaScript. ---

## 🛠️ Технологический стек
