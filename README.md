# ⚡ San Diego RP — Automation Script & Web Hub

A high-performance, responsive landing page and product showcase for the **San Diego RP (Roblox)** automation script. Designed in a modern dark-orange aesthetic with real-time UI previews, tier breakdowns, and injector compatibility matrix.

---

## 🚀 Key Script Features

- **Extreme Velocity (350 studs/s):** High-speed travel across highway sectors without artificial slowdowns.
- **Checkpoint Bypass (GhostBarriers):** Seamlessly passes checkpoints (KPP), fences, and barriers by dynamically toggling collision geometry.
- **Auto Interaction & Alignment:** Automatic ProximityPrompt (E-key) detection, angle alignment, and auto-purchase routines.
- **Multiple Farm Modes:** Support for Mona Lisa, El Capo, and Cargo Truck rotations.
- **Customizable Themes:** Switch dynamically between *Dark Graphite* and *Indigo Neon* UI layouts.

---

## 🌐 Web Hub Features

- **Dynamic Theme Switcher:** Interactive live preview of script GUI themes (*Dark Graphite* / *Indigo Neon*).
- **Interactive Pricing Matrix:** Clear tiers (1-Day Trial, 1-Week, 1-Month, and Lifetime keys).
- **Compatibility Matrix:** Up-to-date compatibility and sUNC ratings across popular injectors (Real, Xeno, Solara, Delta, Volt, Wave).
- **Direct Checkout Flow:** Instant access to Telegram and Discord contacts with one-click clipboard copying.
- **Zero External Dependencies:** Built with pure HTML5, CSS3 (Flexbox/Grid/Animations), and vanilla JavaScript.

---

## 🛠️ Tech Stack

- **Markup:** HTML5 (semantic structure)
- **Styling:** Vanilla CSS3 (custom properties, modern glassmorphism, responsive design)
- **Scripting:** Vanilla JavaScript (ES6+, Intersection Observer API, Clipboard API)
- **Automation / Logic:** Luau / Roblox Studio API (Raycasting, BodyMovers/LinearVelocity)
